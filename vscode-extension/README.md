# 설이코드 VS Code 확장 (독립 실행형)

## 기능
- \`.seol\` 파일 자동 인식 및 문법 색상 강조
- 괄호 자동 닫기와 들여쓰기
- 한국어 코드 조각
- 편집기 오른쪽 위 ▶ 실행 버튼 및 F5 실행
- **설이코드: 카카오봇 연결 파일 만들기** 명령으로 MessengerBotR용 JavaScript 자동 생성
- 실행 결과는 VS Code 통합 터미널에 표시
- Windows x64용 설이코드 실행기(EXE)를 확장에 포함

## 설치 및 사용
1. GitHub 저장소의 Actions에서 **SeolCode-Standalone-VSCode-Extension** 아티팩트를 내려받습니다.
2. ZIP 압축을 풀어 안에 있는 \`.vsix\` 파일을 찾습니다.
3. VS Code 확장 탭의 ... 메뉴 > **Install from VSIX...** 에서 해당 파일을 선택합니다.
4. VS Code를 다시 로드합니다.
5. 아무 폴더나 열고 \`.seol\` 파일을 만든 뒤 ▶ 또는 F5로 실행합니다.

## 카카오봇 만들기
1. \`.seol\` 파일에 아래처럼 명령어를 작성합니다.

~~~text
명령어("!안녕", "안녕하세요! 설이 카카오봇입니다.")
명령어("!도움말", "설이 카카오봇 명령어 목록입니다.")
~~~

2. 편집기 오른쪽 위의 카카오봇 변환 아이콘을 누르거나 명령 팔레트에서 **설이코드: 카카오봇 연결 파일 만들기**를 실행합니다.
3. 같은 폴더에 생성된 \`.js\` 파일을 휴대폰으로 옮깁니다.
4. MessengerBotR에서 스크립트로 등록하고 활성화합니다.

현재 카카오봇 변환기는 고정 문자열 응답을 지원합니다. 변수·조건문·계좌·송금·저장 기능은 다음 단계에서 추가할 예정입니다. MessengerBotR은 생성된 연결 코드를 실행하는 역할이며, 봇 명령어 원본은 설이코드 \`.seol\` 파일입니다.

## 독립 실행형 안내
이 확장 패키지에는 Windows x64용 설이코드 인터프리터 실행 파일이 포함됩니다. 사용자는 별도로 Python을 설치하거나 \`seol.py\`를 준비할 필요가 없습니다. 실행기 코드는 프로젝트의 설이코드 실행기와 카카오봇 변환기를 PyInstaller로 묶어 빌드합니다.

현재 제공 대상은 Windows x64입니다. 다른 운영체제용 확장 패키지는 별도 빌드가 필요합니다.
