# 설이코드 (SEOL CODE)

한국어 문법으로 작성하고 Python으로 실행하는 초보자용 프로그래밍 언어입니다.

> 현재 버전: **0.1.0 (초기 실험판)**

## 시작하기

Python 3.10 이상이 필요합니다. 저장소를 내려받은 뒤 터미널에서 실행하세요.

```bash
python seol.py examples/안녕하세요.seol
```

대화형 모드:

```bash
python seol.py
```

## 첫 번째 프로그램

```text
출력("안녕하세요! 설이코드입니다.")

이름 = "설이"
출력("반가워요, " + 이름)

나이 = 18
만약 나이 >= 18:
    출력("성인입니다.")
아니면:
    출력("미성년자입니다.")

반복 3회:
    출력("설이코드 배우기!")
```

## 지원 문법

| 문법 | 설명 |
| --- | --- |
| `출력(값)` | 화면에 출력 |
| `변수 = 값` | 변수 만들기/값 바꾸기 |
| `만약 조건:` | 조건문 |
| `아니면:` | 조건이 거짓일 때 실행 |
| `반복 숫자회:` | 정해진 횟수만큼 반복 |
| `함수 이름(매개변수):` | 함수 정의 |
| `반환 값` | 함수 결과 반환 |
| `그리고`, `또는`, `아니다` | 논리 연산 |

숫자, 문자열, 참/거짓(`참`, `거짓`), 사칙연산, 비교연산을 지원합니다.

## 함수 예제

```text
함수 인사하기(이름):
    출력("안녕하세요, " + 이름)

인사하기("설이")
```

## 보안과 제한

- 임의의 Python 코드 실행(`import`, 파일 접근, 시스템 명령 등)은 허용하지 않습니다.
- 현재는 학습용 초기 버전이며, 클래스·모듈·외부 라이브러리·카카오톡 API는 아직 지원하지 않습니다.
- 카카오톡 봇 연동은 플랫폼에서 허용하는 API와 실행 환경을 확인한 뒤 별도 기능으로 개발할 예정입니다.
