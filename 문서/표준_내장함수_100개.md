# 설이코드 표준 내장 함수 100개 (v0.3.0)

## 사용 예제

~~~text
숫자들 = [10, 20, 30, 40]
출력("평균:", 평균(숫자들))
출력("최댓값:", 숫자최댓값(숫자들))
출력("제곱근:", 제곱근(81))

이름 = "  seol code  "
출력(대문자(공백제거(이름)))
출력(문자나누기("사과,배,포도", ","))

과일 = ["사과", "배"]
목록추가(과일, "포도")
출력(마지막항목(과일))
출력(중복제거(["가", "나", "가"]))

사용자 = {"이름": "설이", "레벨": 3}
출력(사전키(사용자))
출력(JSON문자열(사용자))
출력(오늘날짜())
~~~

## 참고
- 내장 함수는 seol_builtins.py에 구현되어 있습니다.
- 이 100개는 0.3.0에서 실제 호출 가능한 함수입니다.
- 파일·네트워크·운영체제 명령 실행 함수는 안전성과 권한 설계를 먼저 한 뒤 별도 표준 모듈로 추가합니다.
- 수학 통계 함수 중 일부(평균, 중앙값, 분산 등)는 데이터 개수가 부족하거나 자료형이 맞지 않으면 오류를 반환할 수 있습니다.
