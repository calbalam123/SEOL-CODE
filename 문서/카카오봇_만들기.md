# 설이코드로 카카오톡 봇 만들기 (MessengerBotR)

설이코드의 \`.seol\` 파일에 명령어와 답변을 작성하고, 변환 도구로 MessengerBotR에서 실행할 연결 파일을 만듭니다.

## 1. 설이코드 파일 작성

예를 들어 \`예제/카카오봇_시작.seol\` 파일을 엽니다.

~~~text
명령어("!안녕", "안녕하세요! 설이 카카오봇입니다.")
명령어("!도움말", "설이 카카오봇 명령어 목록입니다.")
명령어("!버전", "설이 카카오봇 0.1.0")
~~~

현재 카카오봇 첫 버전은 \`명령어("명령", "고정 응답")\` 선언을 지원합니다. 일반 변수, 조건문, 계좌 데이터 연동은 아직 지원하지 않습니다.

## 2. MessengerBotR 연결 파일 생성

설이코드 프로젝트 폴더에서 다음 명령을 실행합니다.

~~~powershell
python seol_bot.py "예제/카카오봇_시작.seol" "dist/설이카카오봇.js"
~~~

성공하면 \`dist/설이카카오봇.js\` 파일이 만들어집니다.

## 3. MessengerBotR에 등록

1. 생성된 \`dist/설이카카오봇.js\` 파일을 휴대폰으로 옮깁니다.
2. MessengerBotR에서 새 스크립트를 만들거나 기존 스크립트를 엽니다.
3. 생성된 JavaScript 내용을 스크립트에 넣고 저장합니다.
4. 스크립트를 활성화한 뒤 오픈채팅방에서 \`!안녕\`을 입력해 테스트합니다.

## 작동 구조

- 봇의 명령어와 답변 원본: 설이코드 \`.seol\` 파일
- 변환기: \`seol_bot.py\`
- 카카오톡 메시지 수신 및 답변 전달: MessengerBotR 연결 코드

MessengerBotR은 설이코드 인터프리터를 직접 실행하지 않으므로, 현재 방식은 설이코드 원본을 MessengerBotR 호환 코드로 변환합니다. 생성된 연결 코드는 MessengerBotR의 스크립트 엔진에서 실행됩니다.

## 현재 제한

- 고정 문자열 응답만 지원합니다.
- 같은 명령어를 중복 등록할 수 없습니다.
- 계좌·잔액·송금 및 영구 저장 기능은 아직 구현되지 않았습니다.
- 카카오톡 자동응답은 MessengerBotR과 카카오톡의 정책 및 기기 상태에 영향을 받습니다.
