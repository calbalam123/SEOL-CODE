# 설이코드 카카오봇 만들기 (MessengerBotR)

## 고정 응답

~~~text
명령어("!안녕", "안녕하세요! 설이 카카오봇입니다.")
~~~

## 실제 메시지 정보 사용

~~~text
명령어("!내정보"):
    답장("사용자: " + 보낸사람())
    답장("방 이름: " + 방이름())

명령어("!따라하기"):
    답장("받은 메시지: " + 메시지())
~~~

지원 함수:
- \`답장("문장")\`: 카카오톡 방에 답장을 보냅니다.
- \`보낸사람()\`: 발신자 이름을 가져옵니다.
- \`방이름()\`: 메시지가 온 방 이름을 가져옵니다.
- \`메시지()\`: 수신된 메시지 원문을 가져옵니다.

## 변환 및 등록

VS Code에서 \`.seol\` 파일을 열고 **설이코드: 카카오봇 연결 파일 만들기**를 실행합니다. 같은 폴더에 생성된 \`.js\` 파일을 MessengerBotR 스크립트로 등록합니다.

소스 저장소에서 직접 변환할 때:

~~~powershell
python seol_bot.py "예제/카카오봇_시작.seol" "dist/설이카카오봇.js"
~~~

## 제한

설이코드 파일이 명령어 원본이며 변환기가 MessengerBotR용 JavaScript를 생성합니다. 현재 명령어 블록은 \`답장()\`과 \`보낸사람()\`, \`방이름()\`, \`메시지()\`를 지원합니다. 계좌 저장, 변수, 조건문, 송금은 아직 구현되지 않았습니다. 실제 전달되는 발신자와 방 이름은 MessengerBotR 버전과 실행 환경에 따라 달라질 수 있습니다.
