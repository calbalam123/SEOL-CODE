# 설이코드 카카오봇 만들기 (MessengerBotR)

## 1. 기본 명령어

```text
명령어("!안녕", "안녕하세요! 설이 카카오봇입니다.")
```

## 2. 계좌·잔액·송금 기능

파일 맨 위에서 시작 잔액을 설정합니다. 아래 예제는 처음 계좌를 만드는 사용자에게 10,000원을 지급합니다.

```text
경제시스템(10000)

명령어("!계좌"):
    계좌확인()

명령어("!잔액"):
    잔액확인()

명령어("!송금"):
    송금처리()
```

카카오톡에서 사용하는 명령어:
- `!계좌`: 처음 사용하면 계좌를 만들고 현재 잔액을 보여줍니다.
- `!잔액`: 잔액을 확인합니다. 계좌가 없으면 시작 잔액으로 개설됩니다.
- `!송금 홍길동 1000`: 홍길동에게 1,000원을 보냅니다. 받는 사람도 먼저 `!계좌`를 입력해야 합니다.
- `!도움말`: 예제 파일에 등록된 명령어를 안내합니다.

## 3. 데이터 저장과 주의사항

계좌 데이터는 MessengerBotR의 `FileStream.read()`와 `FileStream.write()`를 사용해 휴대폰의 `/sdcard/SEOL_CODE_accounts.json` 파일에 저장합니다. 앱을 종료하거나 휴대폰을 재시작해도 파일이 유지되는 저장 방식입니다. MessengerBotR 버전의 파일 접근 권한과 저장소 정책에 따라 경로 접근이 제한될 수 있으므로, 처음 실행 후 파일 저장 오류가 없는지 확인하세요.

현재 계좌 식별자는 MessengerBotR이 전달하는 발신자 닉네임입니다. 따라서 닉네임을 바꾸면 기존 계좌와 다른 계좌로 인식될 수 있습니다. 송금은 같은 봇이 실행되는 저장 파일 안에서만 처리됩니다.

## 4. 변환 및 등록

VS Code에서 `.seol` 파일을 열고 **설이코드: 카카오봇 연결 파일 만들기**를 실행합니다. 생성된 `.js` 파일을 MessengerBotR 스크립트로 등록합니다.

명령줄에서 변환할 때:

```powershell
python seol_bot.py "예제/카카오봇_시작.seol" "dist/설이카카오봇.js"
```

## 5. 지원 문법

- `경제시스템(시작잔액)`: 계좌 시스템과 최초 지급액을 설정합니다.
- `명령어("!명령", "고정 응답")`: 고정 응답 명령어입니다.
- `명령어("!명령"):`: 동작을 작성하는 명령어 블록입니다.
- `답장("문장")`: 메시지에 답장합니다.
- `보낸사람()`, `방이름()`, `메시지()`: 현재 메시지 정보를 가져옵니다.
- `계좌확인()`, `잔액확인()`, `송금처리()`: 계좌 기능입니다.

계좌 식별은 닉네임 기반의 간단한 초기 버전입니다. 실제 사용자 고유 ID 연동, 관리자 지급·회수, 거래 기록, 다중 국가별 통화는 다음 단계에서 확장할 수 있습니다.
